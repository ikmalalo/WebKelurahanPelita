# Kelurahan Pelita Web Portal 🏛️

Website portal resmi Kelurahan Pelita, Samarinda Kota. Platform ini dirancang untuk mendigitalisasi layanan kelurahan, memberdayakan UMKM lokal, dan menyediakan akses mudah ke materi pelatihan digital.

## ✨ Fitur Utama

- **🏠 Beranda Dinamis**: *User-interface* premium dengan navigasi animasi dan informasi program unggulan.
- **🛍️ Direktori UMKM**: Katalog produk usaha lokal yang dilengkapi dengan detail produk, galeri foto, dan fitur filter kategori (Makanan Berat, Ringan, Dessert, Drink).
- **📚 Materi Pelatihan (Learning Management)**: Akses materi edukasi digital untuk UMKM (Branding AI, Marketplace, QRIS, Google Maps) dengan tampilan progresif dan navigasi *Daftar Isi* yang cerdas.
- **💬 Forum Helpdesk**: Wadah interaksi warga untuk bertanya dan berdiskusi seputar layanan kelurahan.
- **🔐 Portal Masuk**: Sistem login terpadu dengan desain *glassmorphism* modern.
- **📱 Responsif**: Optimal untuk berbagai perangkat, mulai dari desktop hingga telepon genggam.

## 🚀 Teknologi yang Digunakan

- **Frontend**: [React.js](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS (Custom Premium Design)
- **Icons**: SVG & Lucide-inspired patterns
- **Asset**: Unsplash (Placeholder Images)

## 🛠️ Cara Instalasi & Menjalankan

1.  **Clone repositori ini:**
    ```bash
    git clone https://github.com/ikmalalo/WebKelurahanPelita.git
    cd WebKelurahanPelita/ProjekKelurahanPelita
    ```

2.  **Install dependensi:**
    ```bash
    npm install
    ```

3.  **Jalankan di mode pengembangan:**
    ```bash
    npm run dev
    ```

4.  **Akses website:**
    Buka [http://localhost:5173](http://localhost:5173) di browser Anda.
